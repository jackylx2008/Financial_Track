## 信用卡差额退款关联与净额展示

- 信用卡/贷记卡退款关系扩展为三类：同金额的“交易取消退款”、同时满足绝对差额和差额比例阈值的
  “差额退款”，以及超过阈值、需要人工确认差额性质的“普通部分退款”。借记卡不参与该规则。
- 非全额退款必须满足同一机构、同一卡片、同币种、同一商户、退款发生在原支出之后且不超过配置天数，
  同时退款收入的摘要或商户字段必须含退款、退货、退单、撤销或冲正语义。
- 审核页对差额退款使用浅黄色整行斜线关联显示，详情保留原支出、退款及未退差额；金额汇总只将未退差额计入
  支出。普通部分退款使用浅蓝色显示，保留收入、支出原金额分别汇总，等待人工判断差额是否为手续费等成本。
- 新增 `bank_transaction_review.partial_refund_max_difference`（默认 200 元）和
  `partial_refund_max_difference_ratio`（默认 5%），均支持环境变量覆盖。
- 匹配改为“全额退款 → 小差额退款 → 普通部分退款”三阶段，候选按金额最接近优先、时间最近次优，防止
  普通部分退款提前占用更准确的差额退款原支出。
- 使用现有归一化数据重建本地审核页后，2021-05-28 的 24,896 元支出与 2021-06-05 的 24,800 元退款
  已正确关联，页面显示 96 元净支出，金额汇总不再把 24,896 元和 24,800 元分别重复累计。本次未重新 OCR
  人工确认过的 PDF，也未调用本地 AI。
