# 2026-09-20 银行卡类型与月账单归一化更新

## 1. 银行和卡片类型修正

- 交通银行本批 7 份 PDF 均为借记卡交易流水；不再按 16 位账号推断为信用卡，也不再显示未识别卡片。
- 建设银行来源为个人活期账户交易明细，全部标记为借记卡。摘要中的“信用卡还款”表示交易用途，不代表本方账户是信用卡。
- 邮件机构识别改为优先匹配发件人和银行专名，修复工行月账单被招商银行的通用“信用卡/账单/尾号”规则抢先命中的问题。
- 招商银行真实电子月账单新增交易块解析，保存消费、还款、交易日、入账日、商户及卡尾号。

## 2. 工商银行月账单与打印流水比对

- 工行月度信用卡账单逐笔提取交易卡尾号、交易日、入账日、交易类型、商户、金额、方向及主卡/副卡角色。
- 信用卡打印流水同步保存交易卡尾号；月账单与打印流水按银行、日期、方向、金额、交易卡尾号和商户进行强匹配。
- 商户文字不能完全对应时，仅在其余字段一致且候选唯一时合并；匹配持续执行到结果稳定，重复运行不再产生新合并。
- 合并记录使用 PDF 的精确交易时间，保留月账单完整摘要、主副卡角色、账户尾号及全部邮件/PDF 来源。
- 信用卡还款继续保留邮件账单中的完整还款摘要。

## 3. 审核 HTML

- `bank_transactions_full_review.html` 新增“交易卡尾号”和“主/副卡”列。
- 原“卡号尾号”明确改名为“账户尾号”，用于展示打印流水对应的账户或共享额度卡尾号。
- 当前审核集不再出现交通银行信用卡、交通银行未识别卡片、建设银行信用卡或工商银行未识别卡片。

## 4. 当前数据结果

- 原始候选流水 47,532 条，过滤 46 条非交易内容，最终归一化为 20,180 条。
- 工行共享额度跨卡合并 14,371 次；工行月账单与打印流水匹配 12,852 次，其中信用卡还款 32 次。
- 当前分类：工商银行信用卡 14,463 条、工商银行借记卡 4,577 条、交通银行借记卡 522 条、建设银行借记卡 614 条、招商银行信用卡 4 条。
- 工行信用卡记录中保存主卡角色 8,529 条、副卡角色 4,190 条；其余仅有打印流水来源的记录暂无月账单角色。
- 7 份交通银行 PDF 共 44 页按需调用本地 AI/OCR，全部成功，无未解决附件。
- 银行流水和统一财务事实均为 20,180 条，完整指纹、来源哈希及修正前后版本关系继续保留。
- 补回 12,600 个旧版共享卡中间版本，使更早的单卡记录、共享账户版本与当前月账单合并版本形成连续历史链；其中 199 个已不再由当前原始解析结果产生的旧版本作为历史终点保留。
